## 🔧 Troubleshooting

### "Vite server stopped"
```bash
# Restart Vite
npm run dev
```

### "Demo page shows but no styling"
- Make sure Vite is running (`npm run dev`)
- Check Vite output in terminal
- Hard refresh browser (Ctrl+F5)

### "Want to stop servers"
- Press `Ctrl+C` in the terminal running Vite
- Press `Ctrl+C` in the terminal running PHP (if started)
